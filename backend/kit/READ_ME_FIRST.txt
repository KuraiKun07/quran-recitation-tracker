QURAN TRACKER - READ ME FIRST

Which zip?
   QuranTracker-...-gpu.zip   for a PC with an NVIDIA graphics card (faster results)
   QuranTracker-...-cpu.zip   for any other Windows 10/11 64-bit PC (smaller download)
   Both work without internet. If unsure, take the cpu one; it runs everywhere.

1. Unzip the WHOLE folder to a short place such as C:\QuranTracker
   (right-click the zip, Extract All). Do not run it from inside the zip.
2. Double-click Start.bat.
   The first start sets the app up from the included files (a few minutes, no internet
   needed). Later starts are quick.
3. If Windows shows "Windows protected your PC": click More info, then Run anyway.
   If it asks permission to install the Microsoft Visual C++ runtime: click Yes.
4. Your browser opens the app. Allow the microphone when it asks.
   Use Chrome or Edge. If the browser does not open, go to http://localhost:8000/
5. Keep the black window open while you use the app. Close it to stop.

Your voice is processed on this computer only. Nothing is uploaded.

Colours: green = correct, orange = probably a mistake (check it), red = a mistake or a
skipped word. Click an orange or red word to see what was heard.
When you pause, the app listens to what you said once more, letter by letter: a green word
can then turn orange if a commonly confused letter was heard (for example h instead of H).

This app is a practice aid. Its colours can be wrong, and it does not replace a qualified
Quran teacher (shaykh / muqri').

Problems? Send the "logs" folder (it appears after the first start) to the person who shared the app.
